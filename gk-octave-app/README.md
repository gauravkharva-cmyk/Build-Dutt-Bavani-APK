# GK Octave Analyzer 1.3
Offline FFT octave/third-octave analysis, Leq, measurement timer and CSV export. NEW: optional *assumed quiet-room SPL estimate* without external calibrator, with a baseline in dBFS and user selected assumed dBA. The result is not calibrated and may have very large error. Values are visibly marked estimated, never certified. Do not use for motor acceptance, regulatory tests or hearing protection. Default raw dBFS mode is available. Developed By: Gaurav Kharva.
