# GK Image to Video

Android offline image-to-MP4 slideshow creator.

- Pick multiple JPG/PNG/HEIC photos using Android's secure file picker.
- Set each picture to 1, 2, 3, 5 or 10 seconds.
- Change order with up/down controls, remove individual photos.
- Output landscape HD, portrait HD, square HD, or landscape Full HD.
- Generates H.264 MP4 with Android MediaCodec, OpenGL ES and MediaMuxer.
- Choose a folder and file name through Android's Save dialog.
- No internet permissions, no ads, no watermark.

## Install APK
After the GitHub workflow succeeds, download [GK-Image-to-Video.apk](downloads/GK-Image-to-Video.apk?raw=1) from this branch, or fetch the Actions artifact.
This is an APK signed with a development/debug signing key and intended for personal installation, not Play Store publishing.
